# BeadDiff

运行在 Windows 本机的电商商品整理工作台。使用 **Python 3.12 + PySide6 + SQLite**，用于接收妙手采集插件的原始材料、解析商品、编辑 SKU、审核并导出妙手字段表格。

## 启动

当前 `learner` 环境已有 PySide6 和 openpyxl，无需重建 Conda 环境。

```bat
conda activate learner
cd /d E:\workspace\BeadDiff
python main.py
```

也可以双击项目中的 `start.bat`，直接使用已确认的解释器 `E:\pySpace\anaconda\envs\learner\python.exe`。解释器路径变动时请改启动脚本，或用上面的命令。

只有其他环境缺少依赖时，才需要执行：

```bat
python -m pip install -r requirements.txt
```

PyCharm 请将项目解释器设为 `E:\pySpace\anaconda\envs\learner\python.exe`，运行根目录的 `main.py`。

## 采集材料

已确认的实际流程是 Temu 页面材料通过 `/open/fetch/pfti` 上传到妙手相关服务。BeadDiff 接收的是同一份上传前材料，不依赖妙手返回商品 JSON。

支持的 JSON 形式：

```json
{
  "eventId": "每次采集生成 UUID，重试沿用原 UUID",
  "requestUrl": "https://kuajing-plw.happyporsche.com/open/fetch/pfti",
  "payload": {
    "source": "temu",
    "site": "US",
    "itemId": "实际商品 ID",
    "afterUrl": "https://www.temu.com/实际商品链接",
    "pageContent": "包含商品 JSON 的完整 HTML 字符串",
    "productExtInfo": "{\"sizeChatInfo\":null}"
  }
}
```

也支持直接导入 `payload` 对象及对象数组。HAR 只提取 pfti 的请求正文，不复制其中的请求头、Cookie 或响应。若浏览器省略了请求正文，请另存 Payload，或接通插件转发。

<!-- 解析器静态读取页面中的 window.rawData、初始 JSON 和 OpenGraph 摘要；不执行网页脚本。首版映射 store.goods / goodsName / skuList / specs 等已知字段。实际页面存在版本差异；目前没有完整真实 pfti 样本可验证全字段兼容性。 -->
<!-- 2026-10-11：本次修改原因：已取得真实采集材料，按同一商品上下文补齐同级 SKU、属性和媒体字段。 -->
解析器静态读取页面中的 `window.rawData`、初始 JSON 和 OpenGraph 摘要，不执行网页脚本。支持 `store.goods` 的图片和视频，以及同级 `store.sku`、`goodsProperty`、`productDetailFlatList`、`productDetail.floorList`、`localInfo.currency`、`crumbOptList`；兼容原有 `goods.skuList` 和两种规格字段格式。兄弟字段仅关联同一商品上下文，排除其它商品 ID 的 SKU。

已检查本机真实浴室垫采集材料，原文包含 9 个 SKU、13 项属性、16 张去重主图、7 张详情图、USD 币种和视频链接。这是本次字段映射的依据；其它 Temu 页面版本仍可能有结构差异。未识别字段保留原始材料，缺失项显示“待完善”。

来源价格优先使用明确的当前售价展示文本，如 `$9.79`，不会把 `979` 自动除以 100 或执行汇率换算。来源币种、来源库存、限购数量、在售状态独立保存并只读展示；自有库存、实际售价和包装重量/尺寸仍由用户填写。

## AI 功能

进入“设置 → AI 模型”，填写厂商、URL、API Key 和模型名称；文本与图片各自支持多个配置，并选择当前使用项。配置保存于 `data/ai_models.local.json`，启动自动读取，已加入 Git 忽略，可编辑、删除、新增和手工重载。

采集商品编辑时，在标题、简述、详情旁点击“AI 处理”；图片可逐张改图或生成有序套图。上传路线从商品库的“上传白底图建商品”进入，使用同一编辑器和 AI 面板。爆款参考可提供文案、图片或提炼后的 Prompt；结果先作为可编辑候选，应用到表单后再保存。

本版实现兼容协议的文本及图片调用，视频仅留占位。上传图和生成图保存在本机；导出妙手前需转为公开图片链接，图片存储上传尚未实现。详细配置、调用方式和验收步骤见 [docs/ai-workflow.md](docs/ai-workflow.md)。
