# BeadDiff

Windows 本机商品加工工具，使用 Python 3.12、PySide6 和 SQLite。支持妙手接口导入、备用插件同步及上传白底图，共用手动编辑和 AI 功能，保存审核后通过接口写回妙手公共采集箱。

## 启动

打包版保留完整的 `dist\BeadDiff` 文件夹，双击 `BeadDiff.exe`；无需激活 Conda。修改源码后，已有 EXE 需由用户重新打包才能使用新功能。

源码运行：

```bat
conda activate learner
cd /d E:\workspace\BeadDiff
python main.py
```

也可双击 `start.bat`。其他环境缺少依赖时安装 `requirements.txt`；运行依赖为 PySide6、HTTPX 和 Pillow。

## 设置与操作

1. **配置。** 在“设置 → 采集路线”选择默认“妙手 ERP 接口”或备用“插件同步”。在“妙手 ERP”填写 AppKey、AppSecret，保存并测试只读连接；非人民币报价还需填写已确认的人民币汇率。文本、图片模型分别在“AI 模型”填写厂商、URL、API Key、模型名，并设为当前。
2. **获取。** 点击“同步妙手采集箱”，查询、勾选并导入；结果留在“采集记录 → 妙手接口”，重复导入保留本机加工内容。备用插件接收原始材料自行解析，也可导入 JSON / HAR / TXT。点击“上传白底图建商品”建立自上传草稿。
3. **加工。** 在“商品加工”按获取方式、平台或审核状态筛选，双击商品分区编辑。标题、简述、详情及图片旁有 AI 按钮；支持爆款参考分析、改图、套图、候选调整和历史。AI 候选应用到字段后还需保存。
4. **保存审核。** 保存前检查字数、数量、链接及数值，失败保留输入；草稿可缺业务必填项。核对后“保存并审核”或批量审核，修改后重新审核当前版本。主图最多 15 张，规格一图片每组最多 10 张。
5. **回传。** 选择“新增加工后的商品”或“更新原商品”，点击商品行“更多 → 传回妙手 ERP · 此商品”，或勾选后使用上方按钮批量回传。新增需独立货源价；更新需经过验证的 ERP 原商品关联，API 导入自动建立关联。检查前置问题后确认账号、位置和方式，再提交。
6. **查看结果。** 回传中显示图片及商品提交阶段；结束后进入“回传记录”查看版本、目标、原因和回执。结果未知先在妙手核对商品 ID，再使用只读核对，避免重复新增。成功后仍需在妙手认领、编辑和发布。

| 页面 | 用途 |
|---|---|
| 商品加工 | 全宽列表展示主图、商品 / 主编号、平台 / 站点、SKU / 属性、售价币种及处理状态；双击或行内编辑 / AI，加工工具在“更多”中 |
| 采集记录 | 切换妙手接口 / 插件历史，查看原始数据、解析原因并进入加工 |
| 回传记录 | 按商品或结果筛选；查看失败建议、接口回执并只读核对未知结果 |
| 设置 | 获取路线、妙手凭证及回传方式、AI 模型、备用插件连接 |
| 操作帮助 | 简明流程、限制及失败处理，提供跳转入口 |
| 回收站 | 查看已移除商品或记录，勾选恢复、永久删除所选或清空当前类型 |

“已修改”表示曾保存内容改动；“已审核”针对当前版本。“已传”要求当前账号及内容与成功回执一致；保存不同内容后显示“需重传”。另外区分未传、未发送、回传中、失败和待核对。

## 备用插件安装

妙手接口路线使用原插件将商品采集到妙手，随后通过接口取数，无需加载 BeadDiff 扩展或启用本机同步。已使用开发版扩展时，可关闭其“启用采集同步”，保留妙手原采集功能。

需要自行解析时：

1. 在“设置 → 采集路线”选择插件同步并保存，进入“插件连接（备用）”复制接收地址和随机密钥。
2. Chrome 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），启用开发者模式。先停用另一套妙手插件，避免重复采集。
3. 点击“加载已解压的扩展程序”，选择 EXE 同目录的 `browser_extension\unpacked`，其中应有 `manifest.json`。源码运行时选择项目根目录下的同名目录。
4. 在扩展“详情 → 扩展程序选项”填写地址和密钥，勾选“启用采集同步”，保存并测试连接。选项打不开时重新加载扩展。
5. 刷新商品页并采集，检查妙手原结果及 BeadDiff 插件记录；接收成功与完整解析分别显示。失败材料可查看原文、重新解析，人工编辑保留。

日常插件同步前启动软件；有暂存任务时在扩展选项立即重试。改变目录、端口或密钥后更新连接配置。仅监听 `127.0.0.1`，切换接口路线后暂停接收，历史数据保留。详细接入契约见 [插件说明](docs/plugin-integration.md)。

## 当前边界与待办

- 写回位置仅支持公共采集箱；授权店铺采集箱显示未开放，需进一步核实接口、授权和字段规范。
- 本机白底图、AI 输出可加工及保存，回传涉及这些图片时需先托管为公网链接；自动素材上传尚未实现。网络图片使用妙手链接上传接口并复用缓存，图片空间不足需在妙手清理或扩容。
- 已适配的文字、数量、数值约束在保存与回传时检查；渠道精确图片尺寸、比例及格式规则仍需逐渠道核实。
- 文本、图片支持已适配的兼容协议；原生协议需额外适配。视频生成保留占位。
- 公共采集箱回传接口已实现，完整真实回传成功仍待确认。接口连接测试成功只证明查询能力。
- 后续补充首次启动向导、自动素材上传、店铺采集箱、多平台解析、批量 AI、串珠物料 / BOM 校验及用户激活。
- Excel 导出代码、入口及运行依赖已移除；已有文件和旧数据库导出记录保留。

## 数据与验证

`data/` 保存数据库、原始材料、版本、素材、候选、记录和日志，已忽略 Git。凭证分别存于 `miaoshou.local.json`、`ai_models.local.json`，启动自动读取；配置文件在本机明文保存。设置中保存的路线不改变商品历史。关闭软件后备份完整数据目录，可用 `BEADDIFF_DATA_DIR` 指定其他位置。

本次仅进行 AST、Ruff 及差异静态检查；未启动软件、编译、运行测试或提交真实 ERP 商品。回归用例供用户自行执行：

```bat
python -m pytest tests -q
```

实现细节见 [ERP 流程](docs/erp-workflow.md) 和 [AI 流程](docs/ai-workflow.md)。
