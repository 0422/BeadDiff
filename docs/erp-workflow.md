## 当前实现边界

此前核实的 `/open/fetch/pfti` 和 `/api/open/niu/push_collect_box` 用于网页材料上传和采集任务提交，不是本次修改后的商品写回契约。来源平台商品 ID 不等于妙手商品 ID，新增返回的目标 ID 也不能自动代替原采集商品 ID。

## 实际操作

1. 重启 `python main.py`，进入“设置 → 妙手回传”，填写妙手开放平台分配的 **AppKey、AppSecret**，点击“保存凭证与汇率”。Apifox 文档密码不能用于调用接口。
2. 若销售价/货源价不是人民币，填写人工确认的汇率，每行形如 `USD=7.20`，表示 1 USD 对应 7.20 CNY。此处数值仅作格式示例，软件不会自动填写。CNY 固定为 1；未配置的币种阻止发送。保存后点击“测试连接（只读）”。
3. 选择并保存回传方式。默认“新增”：保留原采集商品，创建加工后的独立商品。选“更新”时，先在商品速览点击“关联妙手原商品”，按来源商品 ID 查询或直接填写公共采集箱商品 ID，读取详情、人工核对标题/链接/站点后确认关联。关键词结果不等于精确匹配，平台来源 ID 不等于 ERP ID。
4. 编辑商品并保存/审核。在“货源链接”栏目可填写独立“回传货源价”，币种与商品当前币种一致；单规格新增必须有货源价。如果留空，只使用数值与币种明确的采集货源价，不使用销售金额代填。
5. 商品速览可单条回传，勾选商品可批量回传。“回传记录”显示冻结版本、操作方式、目标 ID、实际脱敏响应及失败原因。**当前写入的是公共采集箱**；认领到渠道采集箱、审核和发布仍在妙手操作。

## 凭证与鉴权

凭证文件是 `data/miaoshou.local.json`（设置了 `BEADDIFF_DATA_DIR` 时跟随该目录），与插件接收密钥、AI 模型文件分开。启动时读取并显示已有配置，支持编辑保存、重载及清空凭证。文件及原子保存的临时文件被 `*.local.json` / `*.local.json.*` 忽略；缺失文件不会在启动时自动创建，首次保存时创建。凭证在本机明文存储，界面 AppSecret 遮挡显示；回传日志不保存密钥或请求签名。外部修改/无效 JSON 会阻止覆盖，需先重载/修复。

只调用官方固定地址 `https://openapi-erp.91miaoshou.com`，不复用浏览器登录 Cookie 或采集提交接口。POST JSON 请求头是 `x-app-key`、秒级 `x-timestamp`、`x-sign`，签名为：

```text
HMAC-SHA256(appSecret, appSecret + path + timestamp + appKey + bodyJson + appSecret)
```

签名使用小写十六进制；签名和发送使用同一份 UTF-8 JSON 字节。电脑时间、接口权限、AppKey/AppSecret 和账号 IP 白名单都可能影响调用。测试连接只调用列表查询，不证明新增、更新、图片权限已经获批。

## 字段映射

| BeadDiff 字段 | 公共采集箱请求字段/行为 |
|---|---|
| 产品标题 / 主编号 | `title` / `itemNum` |
| 产品简易描述 | `notesText`，与图文详情分开 |
| 详细描述 / 详情图 | `notes` HTML；详情图嵌入 HTML，没有独立详情图片数组 |
| 产品主图与次序 | `imgUrls`，最多 15 张，按本机排列顺序提交 |
| 产品属性 | `sourceAttrs`，更新按已编辑属性名合并，保留其他远端属性 |
| 货源价 | `price`（CNY），独立于 SKU 售价；单规格必填 |
| 既有 SKU 的商家编号 / 售价 / 库存 | `skuMap` 的 `itemNum` / `price`（CNY）/ `stock` |
| 规格 1 / 规格 2 | 新增时使用 `colorMap` / `sizeMap`，组合键为 `;规格1值;规格2值;`；更新用关联时验证的远端键 |
| SKU 图片 | 绑定到规格 1 的 `colorMap.imgUrl` / `imgUrls`，同一规格 1 的图片须一致 |
| 商品/SKU 重量与包裹尺寸 | `weight`（KG）、`packageLength` / `packageWidth` / `packageHeight`（CM） |
| 视频链接 | `mainImgVideoUrl`；修改时不沿用旧 `mainImgAppVideoId` |
| 尺码表 / 产品认证 / 说明书 | `sizeChart` / `productCertifications` / `guideInfo` |
| 货源链接与备注 | `sourceList.sourceItemUrl` / `remark`；更新须唯一匹配对应来源条目 |

货币转换只影响请求，不改写本机金额/币种。人民币金额按两位小数四舍五入。单规格货源价缺失、未配置币种、主图超过数量、字段超限、图片/附件不是网络链接都会给出明确原因。

## 更新与数据保护

新增调用 `/open/v1/product/common_collect_box/common_collect_box/add_common_collect_box_detail`，产品对象直接作为请求体。

更新先调用 `get_common_collect_box_detail`，获取新鲜的 `editCommonCollectBoxDetail` 和必需 `ossMd5`，再调用同目录下的 `edit_common_collect_box_detail`：

```json
{
  "commonCollectBoxDetailId": 123,
  "editCommonCollectBoxDetail": {"title": "示例：实际会保留其他允许编辑的远端字段"},
  "ossMd5": "来自本次详情读取的值"
}
```

`ossMd5` 是文档要求的字段；不假定它已经证明乐观锁或版本控制。服务器只读字段（`commonCollectBoxDetailId`、`cateList`、`sourceMataInfo`、`sourceSupplierInfo`）不混入可编辑对象。

首次关联前已经保存的手动/AI 改动不会丢失，首次更新使用已有编辑标记。每次成功更新后，以**当时发送的快照**记录增量基线；下次不会重发旧标题/旧售价去覆盖妙手后来修改的值。远端未编辑的售价、货源价、原价、库存、颜色套图、附件、来源信息保持原值。详情图单独修改时保留远端正文和样式。关联及成功回执绑定 AppKey 指纹；更换账号必须重新关联，“已传”显示也按当前账号判断。

SKU 使用首次采集规格核对远端规格名和组合键；无法唯一匹配时阻止该 SKU 的修改，不猜 ID。当前更新支持**既有规格**的编号、售价、库存、物流和规格图，不支持规格维度/组合增删重构，请先在妙手处理。关联后远端规格名称发生变化也会阻止回传。多个认证附件不能被本机单附件入口覆盖。数值字段清空没有明确契约，不能用省略字段冒充已清空；无库存请填 `0`，重量/售价需填写有效数值。

## 图片与发布边界

新使用的网络图片通过官方 `/open/v1/product/picture/picture_space/upload_picture_link` 转入妙手图片空间，再将返回的 `picturePath` 替换进主图、颜色图、尺码表和详情 HTML。未变的远端图片不重复上传，图片准备失败时尚未提交商品。

该图片接口只接受 `imgUrl`。**本地白底图、AI 生成图和 `file:` 地址不能直接上传**：需先在可公开访问的图床/对象存储托管，再替换为 HTTP/HTTPS 链接；本版没有伪造文件上传接口。视频/认证/说明书也需可访问的网络链接。

本版不直接保存 Temu 全托管采集箱，不自动执行认领或平台发布。公共采集箱回传成功与商品已经发布是两个状态。

## 成功、失败与未知结果

只有官方成功响应且返回新增 `commonCollectBoxDetailId` 或更新 `ossMd5` 后，才标记相应发送快照“已传”。修改后再次保存不同内容，新内容仍“未传”；回传期间的新编辑也不会被旧回执标成已传。“已修改”保留曾保存实际改动的状态，导出表格不等于回传。

明确的签名/权限拒绝记为失败；详情查询、字段映射、图片准备失败不会当作可能已保存商品的未知结果。商品保存请求超时、响应缺少必要信息、无法识别的错误或进程中断保留“结果未知”，阻止直接再次发送，尤其不能自动重试新增。

对保存了实际提交内容的未知记录，可在妙手核对来源、标题和时间，找到确切目标 ID，然后点击“核对未知回传（只读）”。程序只读详情，要求原发送账号及目标正确、提交字段全部与远端一致才确认成功；不一致继续保持未知。服务器格式规范化也可能导致严格核对不通过，这时不会强制标成功。旧记录没有实际提交内容时不提供随意清除未知状态的入口。
