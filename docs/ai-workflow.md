# AI 内容处理与模型配置

## 模型在哪里配置

左侧点击“设置”，进入“AI 模型”页，按“文本模型”和“图片模型”分别管理。

1. 点击“新增”，填写厂商、URL、API Key、模型名称。配置名称用于区分用途，可选。
2. 保存后，选中该行点击“设为当前”，或双击该行切换。文本和图片各有自己的当前配置。
3. “编辑”修改配置；“删除”移除配置。删除当前项会清空该类别的当前选择，需要重新选择。
4. “检查接口”仅检查鉴权和模型列表，不生成内容。厂商不提供模型列表时会说明；检查成功不代表该模型支持全部生成能力。

每类可新增多个配置。AI 面板还可临时选择“本次模型”，不修改全局当前项。

文本以兼容 `chat/completions` 协议调用；四项基本信息足以配置采用此协议的服务。图片依据 `micu-image-20260619.html` 的调用形式，支持 `images/generations`、`images/edits` 和通过 `chat/completions` 携带多图进行生图。厂商原生的不同鉴权或请求协议需要另加适配器，不能仅凭厂商名称自动推导。

URL 可填裸域名（自动使用 `/v1`）、接口基础路径、或完整 `chat/completions` / `images/edits` / `images/generations` 地址。明确提供的路径前缀保留。API Key 通过 Bearer 请求头发送。

高级选项：

- 文本的“图片理解”：实际模型支持看图时开启。上传白底图看图写文案、分析爆款参考图需要此能力；纯文字参考无需开启。
- 图片接口模式：“自动”单图走编辑接口，多图走聊天生图；“图片接口”多张通过 `image[]` 发送；“聊天生图”全部通过聊天接口发送。根据厂商实际能力选择。
- 超时：默认 300 秒，可调整。生成请求超时或 5xx 不自动重试；界面提示先核对厂商结果，避免重复提交。

## 独立文件与启动加载

默认配置文件为 `E:\workspace\BeadDiff\data\ai_models.local.json`，启动自动读取并展示。如果设置了 `BEADDIFF_DATA_DIR`，文件随数据目录移动。

文件是独立 JSON，包含 `version`、`profiles`、`active_text_id`、`active_image_id`。每个 profile 使用唯一 `id`，`category` 为 `text` 或 `image`，其余核心字段为 `provider`、`url`、`key`、`modelname`。安全占位示例见 [ai_models.example.json](../examples/ai_models.example.json)。实际账号信息填写到本地文件或软件设置页，示例文件保留占位值。

已填 URL、Key、模型名的配置在启动时会展示；缺字段的配置作为草稿展示，可以编辑，补齐前不能调用。新增、编辑、删除和切换都会保存文件。列表不展示 Key，编辑窗口默认遮挡，可点击“显示”。API Key 保存在本机 JSON 中，未加密。

`data/`、`*.local.json` 及其临时文件均被 `.gitignore` 忽略。任务记录只保存模型公开信息，不保存 API Key 或模型 URL 查询参数。

软件运行期间手动改文件后点击“重新加载配置”。如果外部修改尚未重载，软件会阻止覆盖；JSON 格式损坏时保留原文件、显示原因并停止模型调用，修正后可重新加载。

## 白底图路线

商品加工点击“上传白底图建商品”，选择当前商品的实物图，补充已确认的材质、颜色、尺寸/长度、数量和包装。标题可暂留空。点击“创建并编辑”生成商品草稿并进入同一编辑页，随后使用上述字段按钮处理。

白底图文案面板默认勾选“结合商品主体图写文案”，需要支持图片理解的文本模型；如仅依据已填写事实和参考文案生成，可取消勾选。商品主体图可增加实物角度，爆款图单独上传到风格参考区。

AI 提示限制参考商品的材质、尺寸、颜色、数量等迁移到当前商品。最终结果仍由运营核对；现阶段尚未实现串珠物料/BOM 的自动约束校验。

## 采集箱加工路线

在“采集箱加工”同步商品并进入原编辑页，也可从“回传 ERP”双击商品进入。顶部切换“手动修改 / AI 处理”：整理素材 → 确认方案 → 生成与审核。普通采集商品需明确将目标图片设为调整 / 重做、文案设为改写，填写 Prompt 本身不改变范围；确认方案后开始生成。

结果按主图、详情、SKU 和文案分组留存版本，可编辑候选、重做、勾选采用，再应用到表单。应用后仍需保存修改或保存并审核。部分失败保留成功结果，加工草稿与商品分别保存。

## 代码分工

| 文件 | 作用 |
|---|---|
| beaddiff/ai/config.py | 模型文件加载、保存与类别当前项 |
| beaddiff/ai/client.py | 兼容请求协议、鉴权和响应解析 |
| beaddiff/ai/service.py | 两条路线共用的文案、参考分析、图片与套图任务 |
| beaddiff/ai/jobs.py、beaddiff/assets.py | 候选留档与本机图片素材 |
| beaddiff/ui/ai_workspace.py | 所有字段调用的共用 AI 面板 |
| beaddiff/ui/model_settings.py | 模型新增、编辑、删除、切换和重载 |
| beaddiff/ui/product_creation.py | 白底图商品建档入口 |
| beaddiff/ai/video.py | 视频能力占位接口 |
