## 从原料到锁定配方

1. 在散珠成链新建设计，勾选数据库原料。一次最多选择 24 种，AI 只能引用所选编号。
2. 客户、地区、目标售价区间、材料成本上限和补充要求可留空。商品形式可选成品手链 / DIY 材料包，Listing 语言单独设置；留空的方向由 AI 提议。
3. 点击 AI 生成设计方向，选择方案查看配色、佩戴、展示建议及风险。
4. 串珠段按从线头开始的顺序排列；一段代表连续使用相同原料。用下拉框和数量框修改，支持添加、移除、上下移。配件用量单列，线材和包装不能放在串珠排列中。
5. 系统合并重复原料的 BOM，用十进制按币种分别核算成本；成本、库存缺失明确提示，不自行换汇或补数。成本超限、无法验证已设成本上限、库存不足或资料冲突会阻止锁定。
6. 核对原料、数量、排列及风险后勾选确认并锁定。只有已确认的沿线占长参与长度计算，结果不是佩戴腕围，仍需打样核实。缺少连接材料等风险需人工处理。

锁定后保存当时的原料资料和版本，冻结原料选择与条件；原料后来变更需解锁并重新确认。解锁清空当前 Listing 和图片采用结果，历史版本保留。汇总商品后不能直接改款，应复制为新设计。

设计、图片生成、商品汇总与回传都不扣减或预留原料库存。

## Listing 与图片

锁定后起草 Listing，包括标题、卖点、介绍 HTML 和图片用途。资料只采用来源可信且已确认的事实；文化寓意不应写成疗效。售价、库存、腕围、认证和包装等未知信息需人工补充。

按每行一个用途生成图片，或上传实际打样 / 成品照片。生成只使用配方采用的原料参考图；采用原料缺图时需补图重新锁定，或直接上传实拍。多张图片逐张调用，部分失败会保留成功结果；重试时只填需要重做的用途。

在图片表内勾选采用，选择回传位置：商品主图、详情 / 佩戴图、当前 SKU 图，或主图及当前 SKU。上下移决定采用后的次序。汇总要求 1～15 张主图和恰好一张当前 SKU 图；未采用图片保留在设计中，不进入商品。生成图是概念展示，需人工核对珠子数量、顺序、颜色和 SKU，再打样确认。

每次修改文案、图片采用、用途或顺序后，需重新勾选图文核对。草稿和版本可独立保存，离开时提示保存 / 放弃 / 取消；模型工作期间锁住设计切换，失败保留已保存草稿。

## 汇总、审核与回传

点击“汇总至回传 ERP”创建本地单 SKU 商品，携带设计来源、冻结配方、原料快照、主图、详情图和 SKU 图。同一锁定版本重复汇总返回原商品，不覆盖后续人工编辑；商品在回收站时需先恢复。

售价可暂留空，库存和物流不虚构。进入商品编辑，核对售价币种、独立货源价、库存、实际包裹重量及尺寸后保存并审核。可点击“查看锁定配方”追溯原料和排列；改动图文或规格会取消旧核对状态，需重新勾选核对后才能审核。仅修改售价或库存保留图文核对。

回传 ERP 的列表保留来源筛选、显示列、批量审核、账号回执、历史和批量回传。成链商品首次回传选新增；更新须建立可靠原商品关联。回传时采用的本机图片经过图床托管，再转存妙手；本地配方与素材保留。汇总到列表、审核通过、回传成功、平台发布是不同阶段；成功后仍需在妙手认领和发布。

## 模型与验收

设置 → AI 模型分别保存当前文本、图片配置。外观观察需要支持图片理解的文本模型；不支持视觉的文本模型可根据已填资料生成设计，提示中会说明未读取原料图。生图使用当前图片模型。新模块的设计条件在模块内配置；设置 → 白底图 Listing 仅用于旧过渡入口。

本次仅进行源文件语法树、静态规则和差异检查，未编译、启动软件、执行测试、调用真实模型或向 ERP 发送商品。用户可自行运行回归用例：

```bat
python -m pytest tests/test_bead_workflow.py tests/test_bead_ai.py -q
```

界面验收建议先录入两种不同规格散珠及线材，完成一款打样设计；核对成本缺失 / 冲突拦截、解锁、草稿恢复、部分生图失败、图片用途排序和重复汇总，再验证已有采集商品编辑及回传流程。
